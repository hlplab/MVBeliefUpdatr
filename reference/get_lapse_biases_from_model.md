# Deprecated: get_lapse_biases_from_model

**\[deprecated\]** `get_lapse_biases_from_model()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`get_lapse_bias()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_lapse_bias.md)
instead.

## Usage

``` r
get_lapse_biases_from_model(model, categories = NULL)
```

## Arguments

- model:

  A model object.

- categories:

  Optional vector of category labels to subset.

## Value

Numeric vector of lapse biases.
