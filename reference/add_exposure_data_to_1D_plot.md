# Deprecated: add_exposure_data_to_1D_plot

**\[deprecated\]** `add_exposure_data_to_1D_plot()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`plot_categories()`](https://hlplab.github.io/MVBeliefUpdatr/reference/plot_categories.md)
instead.

## Usage

``` r
add_exposure_data_to_1D_plot(
  data,
  cue.labels,
  category.ids,
  category.labels,
  category.colors
)
```

## Arguments

- data:

  Data frame.

- cue.labels:

  Cue column names.

- category.ids:

  Category values.

- category.labels:

  Category labels.

- category.colors:

  Category colors.

## Value

A list of ggplot layers.
