# Deprecated: sample_observation

**\[deprecated\]** `sample_observation()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`sample_observations()`](https://hlplab.github.io/MVBeliefUpdatr/reference/sample_observations.md)
instead.

## Usage

``` r
sample_observation(x, ...)
```

## Arguments

- x:

  A representation, template, or cognitive model object.

- ...:

  Arguments passed to
  [`sample_observations`](https://hlplab.github.io/MVBeliefUpdatr/reference/sample_observations.md).

## Value

A tibble of sampled observations.
