# Deprecated: get_default_colors

**\[deprecated\]** `get_default_colors()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0.

## Usage

``` r
get_default_colors(var, levels)
```

## Arguments

- var:

  Variable name (`"category"` or `"group"`).

- levels:

  Character vector of factor levels.

## Value

Character vector of color values.
