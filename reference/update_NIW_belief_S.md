# Deprecated: update_NIW_belief_S

**\[deprecated\]** `update_NIW_belief_S()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`update_category_representation()`](https://hlplab.github.io/MVBeliefUpdatr/reference/update_category_representation.md)
instead.

## Usage

``` r
update_NIW_belief_S(kappa_0, m_0, S_0, x_N, x_mean, x_SS)
```

## Arguments

- kappa_0:

  Prior kappa value.

- m_0:

  Prior mean vector.

- S_0:

  Prior scatter matrix.

- x_N:

  Number of observations.

- x_mean:

  Observation mean.

- x_SS:

  Centered observation sum-of-squares matrix.
