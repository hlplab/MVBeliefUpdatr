# Deprecated: get_params

**\[deprecated\]** `get_params()` was deprecated in MVBeliefUpdatr 0.1.0
and will be removed in 0.2.0. Please use
[`get_parameter_names()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_parameters.md)
instead.

## Usage

``` r
get_params(fit, original_pars = FALSE)
```

## Arguments

- fit:

  A stanfit or MVBU_Stanfit object.

- original_pars:

  Whether to return original parameter names.

## See also

[`get_parameter_names()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_parameters.md)
