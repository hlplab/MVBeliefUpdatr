# Deprecated: facet_or_animate

**\[deprecated\]** `facet_or_animate()` was deprecated in MVBeliefUpdatr
0.1.0 and will be removed in 0.2.0.

## Usage

``` r
facet_or_animate(
  p,
  facet_rows_by,
  facet_cols_by,
  facet_wrap_by,
  animate_by,
  animation_follow
)
```

## Arguments

- p:

  A `ggplot` object.

- facet_rows_by:

  Row facet variable.

- facet_cols_by:

  Col facet variable.

- facet_wrap_by:

  Wrap facet variable.

- animate_by:

  Animation variable.

- animation_follow:

  Logical whether animation follows data.

## Value

A `ggplot` or animated object.
