# Deprecated: assert_MVG_ideal_observer

**\[deprecated\]** `assert_MVG_ideal_observer()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use S7
assertions or
[MVG_IdealObserver](https://hlplab.github.io/MVBeliefUpdatr/reference/family-mvg.md)
instead.

## Usage

``` r
assert_MVG_ideal_observer(x, category = "category", verbose = F)
```

## Arguments

- x:

  Object to test.

- category:

  Name of the category field to inspect.

- verbose:

  Logical. Whether to emit additional diagnostics while testing the
  object.

## Value

Invisibly TRUE if the assertion passes.
