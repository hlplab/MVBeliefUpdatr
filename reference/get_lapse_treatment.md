# Get lapse treatment from a cognitive model

Extract lapse treatment from a cognitive model.

## Usage

``` r
get_lapse_treatment(x, ...)

## S7 method for class <MVBU_CognitiveModel>
get_lapse_treatment(x, ...)
```

## Arguments

- x:

  A cognitive model.

## Value

A character string representing the lapse treatment (`"no_lapses"`,
`"sample"`, or `"marginalize"`).
