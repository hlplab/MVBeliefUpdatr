# Deprecated: get_perceptual_noise_from_model

**\[deprecated\]** `get_perceptual_noise_from_model()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`get_noise()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_noise.md)
instead.

## Usage

``` r
get_perceptual_noise_from_model(model)
```

## Arguments

- model:

  A model object.

## Value

Perceptual noise covariance matrix.
