# Deprecated: get_lapse_rate_from_model

**\[deprecated\]** `get_lapse_rate_from_model()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`get_lapse_rate()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_lapse_rate.md)
instead.

## Usage

``` r
get_lapse_rate_from_model(model)
```

## Arguments

- model:

  A model object.

## Value

Numeric lapse rate.
