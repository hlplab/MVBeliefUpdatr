# Deprecated: get_category_levels

**\[deprecated\]** `get_category_levels()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`get_category_labels()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_labels.md)
instead.

## Usage

``` r
get_category_levels(x, indices = NULL, ...)
```

## Arguments

- x:

  A model object.

- indices:

  Optional indices.

- ...:

  Additional arguments.

## See also

[`get_category_labels()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_labels.md)
