# Deprecated: get_cue_dimensionality_from_model

**\[deprecated\]** `get_cue_dimensionality_from_model()` was deprecated
in MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`get_cue_labels()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_labels.md)
instead.

## Usage

``` r
get_cue_dimensionality_from_model(x, indices = NULL)
```

## Arguments

- x:

  A likelihood or model object.

- indices:

  Optional indices (deprecated and ignored).

## Value

A numeric integer.
