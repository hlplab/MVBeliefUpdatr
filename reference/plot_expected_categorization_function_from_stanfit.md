# Deprecated: plot_expected_categorization_function_from_stanfit

**\[deprecated\]**
`plot_expected_categorization_function_from_stanfit()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`plot_categorization_functions()`](https://hlplab.github.io/MVBeliefUpdatr/reference/plot_categorization_functions.md)
instead.

## Usage

``` r
plot_expected_categorization_function_from_stanfit(model, ...)
```

## Arguments

- model:

  Model object.

- ...:

  Arguments passed to
  [`plot_categorization_functions()`](https://hlplab.github.io/MVBeliefUpdatr/reference/plot_categorization_functions.md).
