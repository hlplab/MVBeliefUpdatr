# Deprecated: update_NIW_belief_m

**\[deprecated\]** `update_NIW_belief_m()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`update_category_representation()`](https://hlplab.github.io/MVBeliefUpdatr/reference/update_category_representation.md)
instead.

## Usage

``` r
update_NIW_belief_m(kappa_0, m_0, x_N, x_mean)
```

## Arguments

- kappa_0:

  Prior kappa value.

- m_0:

  Prior mean vector.

- x_N:

  Number of observations.

- x_mean:

  Observation mean.
