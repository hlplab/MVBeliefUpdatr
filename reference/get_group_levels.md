# Deprecated: get_group_levels

**\[deprecated\]** `get_group_levels()` was deprecated in MVBeliefUpdatr
0.1.0 and will be removed in 0.2.0. Please use
[`get_group_labels()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_labels.md)
instead.

## Usage

``` r
get_group_levels(x, indices = NULL, include_prior = FALSE, ...)
```

## Arguments

- x:

  A model object.

- indices:

  Optional indices.

- include_prior:

  Whether to include `"prior"`.

- ...:

  Additional arguments.

[`get_group_labels()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_labels.md)
