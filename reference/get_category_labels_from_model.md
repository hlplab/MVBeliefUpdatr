# Deprecated: get_category_labels_from_model

**\[deprecated\]** `get_category_labels_from_model()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`get_category_labels()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_labels.md)
instead.

## Usage

``` r
get_category_labels_from_model(x, indices = NULL)
```

## Arguments

- x:

  A model, template, or representation.

- indices:

  Optional integer indices of category labels to return.

## Value

Character vector of category labels.

[`get_category_labels()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_labels.md)
