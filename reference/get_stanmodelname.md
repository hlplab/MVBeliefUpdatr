# Deprecated: get_stanmodelname

**\[deprecated\]** `get_stanmodelname()` was deprecated in
MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0. Please use
[`get_family_name()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_model_family.md)
instead.

## Usage

``` r
get_stanmodelname(x, ...)
```

## Arguments

- x:

  A model object.

- ...:

  Additional arguments.

## Value

A character string.

[`get_family_name()`](https://hlplab.github.io/MVBeliefUpdatr/reference/get_model_family.md)
