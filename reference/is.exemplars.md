# Deprecated: is.exemplars

**\[deprecated\]** `is.exemplars()` was deprecated in MVBeliefUpdatr
0.1.0 and will be removed in 0.2.0. Please use S7 validators and
[Exemplar_Model](https://hlplab.github.io/MVBeliefUpdatr/reference/family-exemplar.md)
instead.

## Usage

``` r
is.exemplars(x, group = NULL, verbose = F)
```

## Arguments

- x:

  Object to be checked.

- group:

  Name of one or more group variables, each unique combination of which
  describes a set of exemplars. (default: NULL)

- verbose:

  Logical. If `TRUE`, emits diagnostics.

## Value

A logical.
