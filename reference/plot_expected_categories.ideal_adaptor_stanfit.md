# Deprecated: plot_expected_categories.ideal_adaptor_stanfit

**\[deprecated\]** `plot_expected_categories.ideal_adaptor_stanfit()`
was deprecated in MVBeliefUpdatr 0.1.0 and will be removed in 0.2.0.
Please use
[`plot_categories()`](https://hlplab.github.io/MVBeliefUpdatr/reference/plot_categories.md)
instead.

## Usage

``` r
plot_expected_categories.ideal_adaptor_stanfit(
  model,
  type = "density",
  cues = get_cue_labels(model),
  ...
)
```

## Arguments

- model:

  Model object.

- type:

  Plot type ("density" or "contour").

- cues:

  Cue names to plot.

- ...:

  Arguments passed to
  [`plot_categories()`](https://hlplab.github.io/MVBeliefUpdatr/reference/plot_categories.md).
