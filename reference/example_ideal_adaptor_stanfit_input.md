# Example IdealAdaptorStanfitInput and IdealAdaptorStaninput objects

Constructs example
[`IdealAdaptorStanfitInput`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_StanfitInput.md)
and
[`IdealAdaptorStaninput`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_Staninput.md)
objects from data generated by
[`example_exposure_test_data`](https://hlplab.github.io/MVBeliefUpdatr/reference/example_exposure_test_data.md).

## Usage

``` r
example_ideal_adaptor_stanfit_input(
  model_family = c("NIW", "NIX", "MNIX"),
  n_cues = NULL,
  categories = c("/d/", "/t/"),
  control = control_staninput(),
  data = NULL,
  ...
)

example_ideal_adaptor_staninput(
  model_family = c("NIW", "NIX", "MNIX"),
  n_cues = NULL,
  categories = c("/d/", "/t/"),
  stanmodel = NULL,
  ...
)
```

## Arguments

- model_family:

  Character string indicating the model family: `"NIW"` (default),
  `"NIX"`, or `"MNIX"`.

- n_cues:

  Integer number of acoustic cues (1 or 2). Default: 1 (or 2 for
  `"MNIX"`).

- categories:

  Character vector of length 2 naming the categories. Default:
  `c("/d/", "/t/")`.

- control:

  Named list of Stan input control parameters created by
  [`control_staninput`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_StanfitInput.md).
  Default:
  [`control_staninput()`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_StanfitInput.md).

- data:

  Optional list of `exposure` and `test` tibbles as returned by
  [`example_exposure_test_data`](https://hlplab.github.io/MVBeliefUpdatr/reference/example_exposure_test_data.md).
  If `NULL` (default), data are generated via
  [`example_exposure_test_data`](https://hlplab.github.io/MVBeliefUpdatr/reference/example_exposure_test_data.md).

- ...:

  Additional arguments passed to
  [`example_exposure_test_data`](https://hlplab.github.io/MVBeliefUpdatr/reference/example_exposure_test_data.md)
  when `data` is `NULL`.

- stanmodel:

  Optional character string naming the Stan model for
  `example_ideal_adaptor_staninput`. Defaults to
  `"MNIX_ideal_adaptor_ideal_integrator"` when `model_family == "MNIX"`
  and `"<model_family>_ideal_adaptor"` otherwise.

## Value

For `example_ideal_adaptor_stanfit_input`, an object of class
[`IdealAdaptorStanfitInput`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_StanfitInput.md).
For `example_ideal_adaptor_staninput`, an object of class
[`IdealAdaptorStaninput`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_Staninput.md).

## Details

`example_ideal_adaptor_stanfit_input` constructs the complete high-level
[`IdealAdaptorStanfitInput`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_StanfitInput.md)
object (including data, transform information, and metadata).
`example_ideal_adaptor_staninput` creates a typed Stan-ready input
([`IdealAdaptorStaninput`](https://hlplab.github.io/MVBeliefUpdatr/reference/MVBU_Staninput.md))
via `.new_staninput()`.

## Examples

``` r
# Generate Stanfit input from small synthetic data
stan_input <- example_ideal_adaptor_stanfit_input(
  model_family = "NIX",
  n_cues = 1,
  n_exposure_per_category = 5L,
  n_test_steps_category = 3L,
  n_test_steps_adaptation = 2L,
  n_test_tokens_per_location = 5L
)
stan_input
#> <IdealAdaptorStanfitInput>
#>   Categories (2): /d/, /t/
#>   Cues (1): VOT
#>   Groups (3): no_exposure, left_shifted, right_shifted
#>   Data: 95 rows
```
