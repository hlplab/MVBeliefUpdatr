\chapter{Introduction and Notation Guide}

This document provides formal probabilistic graphical model visualizations for all representation classes, cognitive decision models, and hierarchical Stanfit objects in \texttt{MVBeliefUpdatr}.

For each architecture, figures are presented in two complementary forms:
\begin{enumerate}
  \item \textbf{Boilerplate Plate Notation}: standard directed graphical DAGs illustrating conditional dependencies between latent variables, observed data, sensory percepts, and parameters.
  \item \textbf{Directed Factor Graph Notation}: explicit factor graphs distinguishing probability density factors from variable nodes, following Laura Dietz's framework \cite{Dietz:2010}.
\end{enumerate}

\section{Distinction Between Objects}

\begin{itemize}
  \item \textbf{Category Representations / Templates}: Pure generative models where category parameters ($\mu_c, \sigma^2_c$, $\boldsymbol{\mu}_c, \boldsymbol{\Sigma}_c$, or stored exemplars $y_{j,c}$) are fixed inputs (no circles). Stimulus values $x_n$ are predicted latent outputs (unshaded circle \texttt{latent}), and category labels $c_n$ are observed inputs (shaded circle \texttt{obs}).
  \item \textbf{Cognitive Models (\texttt{MVBU\_CognitiveModel})}: Combine category templates with observer decision behavior, aligned along a single vertical axis from physical stimulus $x_i$ (bottom, \texttt{obs}) through perceptual noise $\sigma_{perc} \to s_i$ (sensory percept, \texttt{latent}), through target multinomial $M$ (weighted by category prior $\pi_c$) and lapse multinomial $M$ (weighted by category lapse prior $\pi_{lapse,c}$ inside the category plate), combined at mixture factor $\mathcal{M}$ (weighted by fixed lapse rate $\lambda$ outside category plate) to generate categorical choice $r_i$ (top, \texttt{obs}). In conjugate models (NIX/NIW), hyperprior parameters ($m_{0,c}, S_{0,c}, \kappa_{0,c}, \nu_{0,c}$) govern the belief distributions over $\mu_c$ and $\sigma^2_c$ ($\boldsymbol{\mu}_c$ and $\boldsymbol{\Sigma}_c$).
  \item \textbf{Stanfit Models (\texttt{MVBU\_Stanfit})}: Hierarchical Bayesian MCMC models with explicit priors over adaptor hyperparameters ($m_{0,c,g}, S_{0,c,g}, \kappa_0, \nu_0$), perceptual noise, latent lapse rate $\lambda$, and category prior $\pi_c$. Belief parameter updating is handled by separate staggered update nodes $\text{Update}_\kappa, \text{Update}_\nu, \text{Update}_m, \text{Update}_S$, outputting four belief parameter circles ($\kappa_{n,c,g}, \nu_{n,c,g}, m_{n,c,g}, S_{n,c,g}$). Test responses are denoted $r_{j,g}$ (\texttt{obs}).
\end{itemize}

\chapter{Univariate Gaussian (UVG) and Normal-Inverse-$\chi^2$ (NIX) Models}

\section{UVG Category Representation and Template}

The UVG representation models each category $c$ by fixed mean parameter $\mu_c$ and variance parameter $\sigma^2_c$. Category label $c_n$ is observed (\texttt{obs}) and stimulus $x_n$ is predicted (\texttt{latent}).

\section{NIX Cognitive Observer Model}

In contrast to UVG, the NIX model explicitly represents belief distributions over category parameters. Hyperpriors ($m_{0,c}, S_{0,c}, \kappa_{0,c}, \nu_{0,c}$) govern latent category parameters $\mu_c$ and $\sigma^2_c$.

\section{NIX Stanfit Hierarchical Bayesian Model}

In the \texttt{NIX\_ideal\_adaptor} Stanfit model, exposure updating uses observed sample statistics ($N_{c,g}, \hat{\mu}_{c,g}, \hat{\sigma}^2_{c,g}$) positioned slightly above the horizontal baseline of prior nodes to avoid arrow collisions. Updating is handled by staggered factor nodes $\text{Update}_\kappa, \text{Update}_\nu, \text{Update}_m, \text{Update}_S$.
