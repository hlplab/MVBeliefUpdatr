When displaying mathematical formulas or equations in the chat window, use clean Unicode math formatting (e.g., superscripts like ², ³, subscripts like ₁, ₂, Greek letters like α, β, θ, μ, σ, and symbols like ±, √, ∑, ≤, ≥, ≠, →).
- For inline math, format using Unicode symbols directly in the text (e.g., *f(x) = ax² + bx + c*).
- For block equations, place them on their own line (optionally in a blockquote or bold).
- Avoid LaTeX delimiters like `\(` or `\[` in the chat window unless explicitly requested.
